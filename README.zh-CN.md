# 🦀 CrabAgent

**本地优先的 AI 工作助手：从对话到成果，贯通文件、浏览器与桌面。**

[English](README.md) | 中文 · [Python 3.12+](https://www.python.org/downloads/) · [许可协议](LICENSE)

CrabAgent 将 AI 对话、任务执行和工作区放在一起。你可以让 Agent 调研问题、编辑代码和 Office 文档、操作浏览器，并在需要时借助 macOS 控制操作本机应用。对话模式适合提问和讨论；处理文件时可切换到工作模式，查看代码、文档或原型。

## 核心能力

- **对话与工作区**：多会话、多工作区，支持 Markdown、代码编辑、文档预览和原型；回复可展示 Mermaid、图表和 KPI 卡片。
- **AI 团队与项目记忆**：按需委派研究、分析、编程和写作任务；支持并行、流水线和交接，并跨会话保存项目知识与偏好。
- **目标和任务**：维护目标、验收条件与进展，支持任务看板、日历、定时任务和会议行动项。
- **文件与文档**：读写工作区文件，创建、编辑和预览 Word、Excel、PowerPoint；支持快照和回滚。
- **浏览器与 macOS 控制**：协作浏览器共享登录状态；macOS 控制可在授权后操作允许列表中的本机应用。验证码、多因素验证等仍由用户处理。
- **渠道与扩展**：支持 MCP、自定义工具、邮件、微信、Tailscale 远程访问，以及 Bark / ntfy 任务推送；相关能力需要各自配置。
- **项目协作**：认领只是编辑意向；同一文件展示在改和已保存的变更，保存时校验版本，避免覆盖。

## 两种工作模式

| | 对话模式 | 工作模式 |
|---|---|---|
| 适用场景 | 提问、讨论、搜索和规划 | 创建或修改文件，边执行边查看成果 |
| 界面 | 会话列表与对话面板 | AI 侧边栏与文档、代码或原型工作区 |
| 常见操作 | 切换模型、调用工具、委派 Agent | 预览 Office 文档、编辑 Markdown、查看代码和会议记录 |

可以在界面中切换模式；Agent 打开或创建文件时也可进入工作区。对话历史仍保留，工作完成后可继续提问。

**例如**，你可以让 Agent 读取一份表格、汇总数据并创建报告；也可以让它检查项目代码、解释修改原因，再运行测试。涉及真实业务数据时，应核对数据来源和结果。

## 快速开始

需要 Python 3.12 或更高版本。

```bash
pip install crabagent
crabagent init

crabagent                  # 交互式 TUI
crabagent --serve          # Web UI：http://localhost:5210
crabagent "帮我整理这个目录"  # 单次 CLI 查询
```

启动后按提示配置模型提供商；也可在设置中配置 ChatGPT 订阅登录、MCP 和其他集成。可选浏览器自动化依赖：

```bash
pip install 'crabagent[browser]'
playwright install chromium
```

Web 服务默认监听 `0.0.0.0:5210`，可能可从其他网络设备访问。远程使用前请检查认证、网络和防火墙配置，避免不必要的暴露。

## 桌面应用

桌面版支持 macOS 和 Windows。安装 CrabAgent 后可构建桌面应用：

```bash
crabagent --build-desktop
```

从源码构建也可使用 `make desktop`（macOS）或 `scripts/build-desktop.ps1`（Windows）。桌面版包含可通过托盘或菜单显示、隐藏的状态宠物。

## AI 团队、目标与记忆

内置 Agent 包括研究员、数据分析师、代码专家、内容撰写员和计划创建者。你可以在对话中指定角色，也可以让 Agent 按任务需要委派、并行处理或以流水线衔接结果；不需要团队时，直接让当前 Agent 完成即可。

目标模式用于持续跟踪一项工作：通过界面的目标按钮或 `/goal <目标>` 创建目标，记录验收条件、约束和检查点。可暂停、继续或查看进度；启用自动继续时，运行受目标状态和预算约束。

项目记忆保存工作区上下文，团队知识、用户偏好和经验可用于后续会话。每轮用户消息会自动注入相关记忆：中文查询按完整词分词，泛词用语料频率过滤，关键词命中与语义（向量）命中融合，改写与精确标识符都能召回。简短约定每轮常驻，长约定以一句话摘要注入，全文按需获取。任务看板、日历和定时任务用于管理持续工作；会议记录可提取行动项。

## 浏览器与桌面控制

**协作浏览器**在嵌入式浏览器中与用户共享登录状态，Agent 可以导航、填写非敏感表单和读取页面。需要登录、验证码或多因素验证时由用户完成；敏感输入和高风险操作受相应限制。

**macOS 控制**需要主动启用并授权应用。首次使用时，按系统提示授予辅助功能和屏幕录制权限；Agent 可观察窗口及其控件，并对允许的应用进行键鼠操作。权限和支持能力以实际系统与应用为准。

## 项目协作与安全边界

同一用户的多个对话可以共享协作记录。显式选择有效工作区的对话可自动加入项目；解绑后不会自动重绑。认领只表示打算改哪个文件或目录、准备改什么；范围重叠会提示，仍可并行编辑。Agent 读取和编辑面板会展示相关意向及已保存摘要，文本差异可按需查看。受管保存会校验版本；遇到过期版本需重读后重新应用改动。未加入项目的对话不会向模型发送项目协作工具。

这是**协作式保护，不是系统级文件锁**：Bash 命令不再自动占用整个工作目录，但 Shell、后台进程和外部编辑器的写入也不受强制互斥；版本检查只能发现部分外部变更。记录按用户隔离，不是跨账号多人协作。

## 远程访问与集成

- **远程访问**：可通过 Tailscale 等受控网络访问 Web UI；先确认服务监听地址、认证和防火墙设置，不要直接将服务暴露到公网。
- **通知与渠道**：在设置中配置 Bark 或 ntfy，可接收任务状态推送；微信和邮件集成需要单独配置和授权。
- **扩展工具**：在设置中连接 MCP 服务；也可以通过 `.crabagent/tools/` 添加自定义工具。工具权限和外部服务权限仍需按用途配置。

## 常用配置与命令

环境变量使用 `CRAB_` 前缀，可通过环境变量或 `.env` 配置。下表列出常用选项，模型与集成也可在界面设置中管理。

| 配置 | 默认值 | 用途 |
|---|---|---|
| `CRAB_SERVE_HOST` / `CRAB_SERVE_PORT` | `0.0.0.0` / `5210` | Web 服务监听地址和端口 |
| `CRAB_DB_URL` | `~/.crabagent/crabagent.db` 对应的 SQLite URL | 数据库连接 |
| `CRAB_MAX_ITERATIONS` / `CRAB_MAX_TOKENS` | `200` / `16384` | Agent 迭代次数和响应 Token 上限 |
| `CRAB_WEB_PROXY` | 空 | 网页搜索与抓取的代理 |

TUI 中可使用 `/help` 查看命令；常用命令包括 `/model`、`/sessions`、`/new`、`/agents`、`/memory`、`/skills`、`/molt` 和 `/todo`。

## 开发

```bash
make install                  # 构建前端并安装可编辑版本
ruff check src/ tests/
pytest tests/

cd frontend && npm run build  # 前端构建
```

主要目录：`src/crabagent/core/`（Agent 与核心能力）、`src/crabagent/serve/`（API）、`frontend/`（Web 界面）、`src/crabagent/electron/`（桌面应用）。
